How this page stays current

Every stat, bar and timeline node above comes from one list called YEARLY_DATA in this file's code — one line per year per category, e.g. { year: 2027, category: "hoc", count: 4, title: "...", note: "..." }. To add next year's record: add one line per category that had activity, save, done. The hero stats, the chart, the six category cards, and the detail panel for every category all recompute themselves — there's only ever this one page and one detail template, never a new page per year or per category.
